# ③ 没看见，却知道 Seeing without Seeing

9/18 · 第 3 周 · 个人 · 材料：Canvas Files 里的网页 · 模块 06 里编号 ⑥A · [网页版](https://changxiang-scu.github.io/aiaa5050/#e3)

## 目的

测“无意识知觉”：箭头闪得太快，你会说没看见；但如果猜方向的正确率明显高于瞎猜，就说明大脑处理了你没意识到的信息（类似盲视）。

## 要求

**要做什么**

网页上一个箭头闪一下，随即被乱码盖住。每题先猜方向（四选一，瞎猜是 25%），再按 S（看见了）或 N（没看见）。共 40 题。

**交什么**

- 结果行和截图发课程群
- 回答三问：
  1. 按 N 的那些题正确率多少、p 多少；
  2. 做的时候是不是觉得在瞎猜；
  3. “有没有看见”谁说了算？判断 AI 有没有觉知，是不是同一个难题？

## 做法

开始前先看页面显示的实际闪现时长。做完把按 N 的题数和其中答对的题数代进 `binom_p.py`，算单侧二项检验的 p 值。

## 代码

[`code/exp3/binom_p.py`](../code/exp3/binom_p.py)，只用标准库：

```bash
python code/exp3/binom_p.py 7 40
```

```text
答对 7/40 = 17.5%，机会水平 25%
单侧 p = 0.904
40 题里至少答对 16 题才 p < 0.05
```

第三个参数可以改机会水平，默认 0.25。

## 提示词

无。

## 结果

闪现 8.4 ms + 遮罩。40 题全按 N，猜对 7 题（17.5%，p = 0.904），没测出“没看见却知道”。

## 反思

- 这次只有 8.4 ms，大约是 120 Hz 屏幕的一帧，比设计的约 33 ms 短很多，可能短到连无意识加工都来不及。所以页面上的实际闪现时长要先看一眼。
- 40 题里至少答对 16 题才 p < 0.05。
