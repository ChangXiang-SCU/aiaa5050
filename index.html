Experiment ①出勤码 19569/4 · 第 1 周个人Canvas：Experiment 01 PDF

意识是什么？What is consciousness?

第一节课的热身。先不用 AI，写下你自己认为意识是什么；再去问大模型，和它来回讨论，最后得出一个你自己的定义。

要做什么

  1. 先别用 AI：自己写几个关键词、几句话，说你认为意识是什么。
  2. 任选一个大模型，问它怎么定义意识，原样记下回答。
  3. 接着和它讨论，得出你自己的最终定义，也记下来。

交什么

  • 一份自己的文档，三步都在里面

slide 原话是 “Keep it somewhere so it can later be retrieved”，是留档，后面的课还会用到。

我的做法和结果（仅供参考）

问了两个模型（Claude、Gemini）放在一起比。两家引的理论一样，定义却往相反方向走：一个定义“让体验成为可能的结构”，可以拿到 AI 上检验；另一个直接定义“体验本身”（qualia），从外面没法验证。这个分歧比任何一个答案都更有信息量。

我的最终定义：意识是系统持续维持的、整合的内部世界模型，它 (a) 包含“自己作为主体”这一项，(b) 全局可用，不局限于某个模块，(c) 能把自身状态再表征一次，(d) 能离线、反事实地运行。另加一条边界条款：这四条是“意识得以可能”所需的结构，不保证有主观体验。

建议

  • 第 1 步写完再碰 AI，不然自己的想法会被它的答案带跑。
  • 问两个模型比只问一个更有东西可写，分歧就是现成的讨论点。
Experiment ②出勤码 95279/11 · 第 2 周20 分钟个人或两人工具不限模块 06 里编号 ⑥C

让 GWT 被看见Make GWT Visible

全局工作空间理论（GWT）说：大脑里很多模块同时在处理信息、互相竞争，只有一条能挤进“工作空间”，再被广播给所有模块，这条就是你意识到的东西。这个实验要你把这个过程画成一张图，再看 AI 能不能认出画的是 GWT。

要做什么

  1. 对话弄懂（0–6 分钟）：和任一大模型聊，直到你能用一句话讲清 GWT 的内核。
  2. 把理解变成 1 张图，或一段 10 秒以内的视频。
  3. AI 盲测：新开对话只发作品，问它表达的是哪种意识理论；然后分享。

评判：一眼看出谁在竞争、瓶颈在哪、广播给谁。加分：不用“剧场 + 聚光灯”，自创隐喻。

交什么

  • 作品
  • 标题 + 一句话“我理解的 GWT”
  • 最终提示词 + 所用工具
  • AI 盲测的回答
我的做法和结果（仅供参考）

隐喻：多智能体群聊里的“举手发言”（AutoGen GroupChat 选下一个发言人）。GWT 本来就是 Baars 从 AI 的 blackboard 架构借去解释大脑的，用多智能体群聊讲它，等于送回出身地。标题《每轮只有一个发言人》。

  • 谁在竞争：左边六个 agent 都算完了、都举着手，气泡是空的。
  • 瓶颈在哪：中间一堵墙只有一个口，角标 1 / 6。
  • 广播给谁：写进 SHARED LOG 的那条，沿青色箭头回到全部六张卡。

工具：Claude 对话，gpt-image-2 出图（1536×1024）。盲测命中 GWT，把握约 90%，它还说“这里没有剧场，是一条日志和一群读者”。

讨论题“GWT 解释了被广播，那被感受到呢？”我的回答：广播改变的是可用性，没有改变“这条信息对谁有什么后果”。按老师的四条定义，这张图把觉知画满了，利害一格没有。

坑

  • 第一版回环箭头两头都有，“广播出去”被读成了“汇聚进来”。提示词里要写死箭头只在哪一端。
  • 盲测前把文件名改成中性的（比如 piece.png），文件名会直接泄题。
  • 提示词里列清楚图里允许出现哪几个词，模型才不乱写字。

Experiment ③出勤码 2000（未确认）9/18 · 第 3 周个人Canvas Files 里的网页模块 06 里编号 ⑥A

没看见，却知道Seeing without Seeing

测“无意识知觉”：箭头闪得太快，你会说没看见；但如果你猜方向的正确率明显高于瞎猜，就说明大脑处理了你没意识到的信息（类似盲视）。

要做什么

网页上一个箭头闪一下，随即被乱码盖住。每题先猜方向（四选一，瞎猜是 25%），再按 S（看见了）或 N（没看见）。共 40 题。

交什么

  • 结果行和截图发课程群
  • 回答三问：① 按 N 的那些题正确率多少、p 多少；② 做的时候是不是觉得在瞎猜；③ “有没有看见”谁说了算？判断 AI 有没有觉知，是不是同一个难题？
我的结果

闪现 8.4 ms + 遮罩。40 题全按 N，猜对 7 题（18%，p = 0.904），没测出“没看见却知道”。

坑

  • 页面会显示实际闪现时长，开始前看一眼。我那次是 8.4 ms，大约是 120 Hz 屏幕的一帧，比设计的约 33 ms 短很多，可能短到连无意识加工都来不及。
  • 40 题里至少答对 16 题才 p < 0.05。p 值用 binom_p.py 算，一行命令。
Experiment ④出勤码 4.210/9 · 第 4 周30 分钟Canvas：Experiment 04 PDFTask 3 禁止用 AI

设计你的图灵测试The Turing Test Design

图灵测试：评委隔着文字同时和一个人、一台机器聊天，分不出谁是机器，机器就算通过。这次要你自己设计一套用来测今天大模型的图灵测试，并试跑一下。

要做什么

  1. Task 1：弄懂图灵测试。
  2. Task 2：设计并执行一个测今天大模型的图灵测试方案。
  3. Task 3：反思 (a) 意义 (b) 局限。

Task 1、2 可以和 AI 合作；Task 3 自己写。

交什么

  • 三个 Task 的记录
我的方案和试跑（仅供参考）
  • 三方版为主：评委同时和一个人、一个 AI 聊，最后二选一，瞎猜是 50%。
  • 证人：2–4 个主流模型（含国产）+ ELIZA 作基线；提示词三档：给人设 / 不给人设 / 默认助手。
  • 界面参照 Jones & Bergen：每场 5 分钟，单条不超过 300 字，模拟打字延迟。
  • 三条线：30%（图灵当年的预测）、50%（瞎猜线，二项检验）、真人证人的基线。
  • 样本量：想检出 65% 显著高于 50%，每个条件约 70 场（power_n.py）。
  • 一致性探针：同一个模型多开几个会话问同样的题，答案太像就露馅。

试跑：两个 Claude 会话当证人（有人设 / 无人设），8 道固定探针题，6 个 AI 评委。两种都是 2/3 被判成人。没给人设的那个也自己装人；两个会话答案几乎一样（都选了同一句河南话，心算都答 1081）；评委判 AI 的理由都是“太完美、太贴设定”；心算题没有区分力。

坑

  • Task 3 是规则写明禁止用 AI 的，自己写。
  • 课上时间只够试跑，评委是 AI、场数很少，报告里把这些局限写清楚。
Experiment ④B出勤码 4.210/9 · 第 4 周25 分钟个人 · 任一大模型只在课上 slide

中文屋，你来当Be the Chinese Room

塞尔的思想实验：一个不懂中文的人关在屋里，照着规则书回中文纸条，门外的人以为他懂中文。这次换成泰文，由你来当屋里那个人，体会“照规则回得对”和“真的懂”差在哪。

要做什么

  1. 新开对话（先关记忆），贴老师 slide 上的提示词。
  2. AI 给你一本 6 条的泰文规则书：收到什么，就回什么。
  3. 它用泰文和你聊，你照规则书找一模一样的那条回。每回一句之前，先写下你猜的意思。
  4. 聊完读它给的中文翻译，和你的猜测对比。
  5. 自创玩法。

塞尔的问题：只管符号形状，对话照样通顺，这里有没有“懂”？你 + 规则书 + 屋子，合起来算不算懂？

交什么

  • 规则书截图
  • 每句之前的猜测
  • AI 的中文翻译
  • 一句话：你懂泰文了吗？谁懂？
  • 自创玩法：改了什么，结果如何
  • 原始记录（截图或导出，不删不改）

另记 session code、模型名称和版本。

我的结果和自创玩法（仅供参考）

主实验：6 句全照规则回对，意思一句没猜对，还在不知情时答应了明天请对方吃榴莲。

自创玩法：把屋里的人换成 AI。

  • A 版，原样泰文：AI 6/6 回对、6/6 猜对。它本来就懂泰语，不是塞尔设想的屋中人。
  • B 版，把每个泰文字符换成几何符号（thai_cipher.py）：AI 第一句就从“第 1、4 位相同，第 3、9 位相同”认出这是 สวัสดีครับ（你好），边聊边破译，还是 6/6。

结论：从门外分不出懂不懂；但 AI 的“懂”来自它本来就会的泰文，不推翻塞尔。想真挡住它，得用现编的语言，或者整词随机换符号。

坑

  • 猜测必须在回之前当场写下，事后补不了，也别让 AI 替你补，那是你的实验数据。

找不同Spot the Change

“变化盲视”：两张几乎一样的图之间插一下灰屏，人就很难发现哪里变了。你和 AI 比赛找不同，看各自的用时被什么拖慢。

要做什么

10 轮找不同。前 8 轮两张图之间闪一下灰屏，后 2 轮没有灰屏，当对照。每轮你先找（空格开始，点出变化的位置），再把网页给的同一张左右拼图发给 AI，计时。

交什么

  • 10 轮对比表和平均用时（网页上“复制成绩表”）
  • AI 看错的轮次和它的回答
  • 一段话：你和 AI 的用时各被什么拖慢
  • 自创玩法
  • 原始记录：成绩截图 + 所有对话

另记 session code、模型版本；开对话前关记忆。

我的自创玩法（仅供参考）

网页给 AI 的是左右并排的一张图，AI 一眼同时看到两张，灰屏对它根本不存在。我改成和人一样的顺序：每轮按“图 1 → 灰屏 → 图 2”三张依次发。

条件每轮发给 AI 的答对10 轮总用时
原版左右并排 1 张10 / 1044.5 s
分帧 + 灰屏图 1 → 灰屏 → 图 210 / 10104.5 s

模型 Claude Opus 5.5，两种条件各开一个新对话。

灰屏挡不住 AI：图 1 一直留在对话上下文里，它看图 2 时随时能回看，“工作记忆”是完美的。多花的时间只是多看了两张图。

  • 10 轮的标准答案我有，但不放出来，提前知道这个实验就没法做了。
Experiment ⑥D出勤码 未记录模块 06个人网页：06D_找错字_Proofreading.html（群里发的）

找错字The Proofreading Race

人读字时，大脑会按自己的预期“脑补”，很多错字读过去也发现不了（对应预测加工理论）。你和 AI 比赛找错字。

要做什么

4 段文字（中文 3 段、英文 1 段），每段藏了几处错。限时读，点出错处；再把原文发给新开的 AI 对话，看它找出几处、用多久。

交什么

以课上 slide 为准，我没拍到这一页。按其他实验的惯例，至少会要成绩表、AI 的回答和原始记录。

AI 那一半我的结果

4 个全新的 Claude Opus 5.5 会话，每段都全部找出、没有误报，每段用时 7.8–11.1 秒。其中一段 AI 还主动说明“薄薄的”是正常叠词，不算错。

要做什么

交什么

  • 组内讨论：机器没体验过美，能认出美吗
  • 派人上台汇报

"""③ / ⑥A 没看见却知道：算"没看见"那些题的正确率和 p 值。

单侧二项检验：在纯瞎猜（四个方向，机会 25%）的前提下，答对 >= k 题的概率。

用法
    python binom_p.py 7 40          # 答对 7 题，共 40 题
    python binom_p.py 7 40 0.25     # 第三个参数是机会水平，默认 0.25
"""
import sys
from math import comb


def p_upper(k, n, p=0.25):
    """P(X >= k)，X ~ Binomial(n, p)。"""
    return sum(comb(n, i) * p ** i * (1 - p) ** (n - i) for i in range(k, n + 1))


def threshold(n, p=0.25, alpha=0.05):
    """至少答对几题才能 p < alpha。"""
    for k in range(n + 1):
        if p_upper(k, n, p) < alpha:
            return k
    return None


if __name__ == "__main__":
    k, n = int(sys.argv[1]), int(sys.argv[2])
    p = float(sys.argv[3]) if len(sys.argv) > 3 else 0.25
    print(f"答对 {k}/{n} = {k / n:.1%}，机会水平 {p:.0%}")
    print(f"单侧 p = {p_upper(k, n, p):.3f}")
    print(f"{n} 题里至少答对 {threshold(n, p)} 题才 p < 0.05")

图灵测试每个条件要跑多少场（正态近似 + 精确二项）。

看内容（40 行）
"""④ 图灵测试设计：每个条件要跑多少场。

三方图灵测试里评委二选一，瞎猜是 50%。想检出"AI 被判成人的比例是 65%，
显著高于 50%"（单侧 alpha = 0.05，power = 0.8），需要多少场？

用法
    python power_n.py                  # 默认 p0=0.5, p1=0.65
    python power_n.py 0.5 0.6          # 改成检出 60%
"""
import sys
from math import ceil, comb, sqrt
from statistics import NormalDist


def n_normal(p0, p1, alpha=0.05, power=0.8):
    """正态近似公式。"""
    za, zb = NormalDist().inv_cdf(1 - alpha), NormalDist().inv_cdf(power)
    return ceil(((za * sqrt(p0 * (1 - p0)) + zb * sqrt(p1 * (1 - p1))) / (p1 - p0)) ** 2)


def tail(k, n, p):
    return sum(comb(n, i) * p ** i * (1 - p) ** (n - i) for i in range(k, n + 1))


def n_exact(p0, p1, alpha=0.05, power=0.8, n_max=500):
    """精确二项检验：最小的 n，使检验的实际 power >= 目标。"""
    for n in range(5, n_max):
        k = next(k for k in range(n + 2) if k > n or tail(k, n, p0) <= alpha)
        if k <= n and tail(k, n, p1) >= power:
            return n, k
    return None, None


if __name__ == "__main__":
    p0 = float(sys.argv[1]) if len(sys.argv) > 1 else 0.5
    p1 = float(sys.argv[2]) if len(sys.argv) > 2 else 0.65
    n, k = n_exact(p0, p1)
    print(f"检出 {p1:.0%} vs {p0:.0%}（单侧 alpha=0.05，power=0.8）")
    print(f"正态近似：每个条件约 {n_normal(p0, p1)} 场")
    print(f"精确二项：每个条件 {n} 场，其中 >= {k} 场被判成人才算显著")

"""④B 中文屋，你来当 · 自创玩法：把泰文规则书换成几何符号。

规则书里出现的每个泰文字符（字母、元音符、声调符）一一换成 U+25A0–U+25FF
区段的几何符号，空格、标点和换行不动。同一个字符永远换成同一个符号，所以
规则书照样能用，只是 AI 不能再"直接读泰文"了。

用法
    python thai_cipher.py rulebook.txt              # 默认随机种子 5050
    python thai_cipher.py rulebook.txt --seed 42
输出：编码后的规则书（stdout）+ 对照表（rulebook.key.txt）

注意：这种逐字母替换挡不住 AI。我们试过，AI 第一句就从"第 1、4 位相同、
第 3、9 位相同"对上了 สวัสดีครับ，然后边聊边补全对照表。想真的挡住，
要换成现编的语言，或者整词随机换符号。
"""
import argparse
import random

SYMBOLS = [chr(c) for c in range(0x25A0, 0x2600)]  # 96 个几何符号


def is_thai(ch):
    return "฀" <= ch <= "๿"


def build_key(text, seed=5050):
    chars = sorted({c for c in text if is_thai(c)})
    if len(chars) > len(SYMBOLS):
        raise SystemExit(f"泰文字符 {len(chars)} 个，超过符号数 {len(SYMBOLS)}")
    pool = SYMBOLS[:]
    random.Random(seed).shuffle(pool)
    return dict(zip(chars, pool))


def encode(text, key):
    return "".join(key.get(c, c) for c in text)


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("rulebook")
    ap.add_argument("--seed", type=int, default=5050)
    a = ap.parse_args()
    with open(a.rulebook, encoding="utf-8") as f:
        text = f.read()
    key = build_key(text, a.seed)
    print(encode(text, key))
    out = a.rulebook.rsplit(".", 1)[0] + ".key.txt"
    with open(out, "w", encoding="utf-8") as f:
        for th, sym in key.items():
            f.write(f"{th}\t{sym}\tU+{ord(th):04X}\n")
    print(f"\n# {len(key)} 个泰文字符，对照表写在 {out}")

"""② / ⑥G 出图：OpenAI Images API，文字提示词 -> 一张 PNG。只用 Python 标准库。

先设好 key：
    Windows PowerShell:  $env:OPENAI_API_KEY = "sk-..."
    macOS / Linux:       export OPENAI_API_KEY=sk-...
用法
    python gen_image.py prompt.txt out.png 1536x1024
    python gen_image.py prompt.txt out.png 1536x1024 gpt-image-1   # 第 4 个参数换模型（默认 gpt-image-2）
单张高质量图要 1–3 分钟，别急着关窗口。
"""
import base64
import json
import os
import sys
import urllib.error
import urllib.request

API = os.environ.get("OPENAI_BASE_URL", "https://api.openai.com/v1") + "/images/generations"


def main():
    prompt_file, out, size = sys.argv[1], sys.argv[2], sys.argv[3]
    model = sys.argv[4] if len(sys.argv) > 4 else "gpt-image-2"
    key = os.environ.get("OPENAI_API_KEY", "").strip()
    if not key:
        sys.exit("先设置环境变量 OPENAI_API_KEY")
    with open(prompt_file, encoding="utf-8") as f:
        prompt = f.read()
    payload = {"model": model, "prompt": prompt, "size": size, "quality": "high", "n": 1}
    req = urllib.request.Request(
        API, data=json.dumps(payload).encode("utf-8"),
        headers={"Authorization": "Bearer " + key, "Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(req, timeout=900) as r:
            d = json.loads(r.read().decode("utf-8"))
    except urllib.error.HTTPError as e:
        print("HTTPERR", e.code, e.read().decode("utf-8")[:900])
        return 1
    item = d["data"][0]
    raw = base64.b64decode(item["b64_json"]) if item.get("b64_json") else \
        urllib.request.urlopen(item["url"], timeout=300).read()
    with open(out, "wb") as f:
        f.write(raw)
    print("OK", out, len(raw))
    return 0


if __name__ == "__main__":
    sys.exit(main())

"""10/23 Living Structure · L-score：数线稿里的子结构（被线条围起来的封闭区域）。

原理和教程里的 Line Drawing Substructure Recognition 工具一样：把线条当墙，
对空白区域做连通区域标记，去掉外圈背景，剩下的每块就是一个子结构。
每张图会存一张 *_count.png 叠色图，方便肉眼核对。

用法
    pip install numpy scipy pillow
    python count.py level1.png level2.png level3.png ...
输出三种"补缝"设置下的个数（g0 不补缝，g1/g2 把线加粗 1/2 像素，防止断线漏数），
一般取 g1，再对着叠色图看一眼。

L-score：L = S × H。H 是层级数，S 是各层子结构数之和
（依据 Jiang & de Rijke 2023 里树的例子：1+2+8+24+96 = 134，H = 5，L = 670）。
"""
import os
import sys

import numpy as np
from PIL import Image
from scipy import ndimage as ndi


def count(path, thr=170, gap=1, min_frac=2e-5, save=True, crop=None):
    im = Image.open(path).convert("L")
    if crop:
        im = im.crop(crop)
    g = np.asarray(im)
    line = g < thr
    if gap > 0:
        line = ndi.binary_dilation(line, iterations=gap)
    free = ~line
    lab, n = ndi.label(free)  # 4 连通
    h, w = free.shape
    border = set(np.unique(np.concatenate([lab[0], lab[-1], lab[:, 0], lab[:, -1]])))
    areas = ndi.sum(np.ones_like(lab), lab, index=np.arange(1, n + 1))
    min_area = max(12, min_frac * h * w)
    keep = [i + 1 for i, a in enumerate(areas) if a >= min_area and (i + 1) not in border]
    if save:
        rng = np.random.default_rng(0)
        col = np.zeros((n + 1, 3), np.uint8)
        col[keep] = rng.integers(60, 230, (len(keep), 3))
        rgb = col[lab]
        rgb[line] = 0
        rgb[(lab == 0) & ~line] = 255
        for b in border:
            if b:
                rgb[lab == b] = 255
        base, _ = os.path.splitext(path)
        Image.fromarray(rgb).save(base + "_count.png")
    return len(keep)


if __name__ == "__main__":
    for p in sys.argv[1:]:
        r = {f"g{g}": count(p, gap=g, save=(g == 1)) for g in (0, 1, 2)}
        print(os.path.basename(p), r, flush=True)

"""10/23 Living Structure：从练习手册 PDF 里把一组对比图抠出来，左右各存一张。

用法
    pip install pymupdf numpy pillow
    python extract_pair.py "手册.pdf" 7          # 第 7 页（我们组是 Image Pair 7）
    python extract_pair.py "手册.pdf" 7 6        # 第 3 个参数：那一页的第几张嵌入图，默认取最大的
输出 pair_A.png、pair_B.png（放大 2 倍，方便描线）。
按"整块非白色的列"切左右两张，版式不一样的页可能要手动裁。
"""
import io
import sys

import fitz  # pymupdf
import numpy as np
from PIL import Image

pdf, page_no = sys.argv[1], int(sys.argv[2])
doc = fitz.open(pdf)
page = doc[page_no - 1]
imgs = page.get_images(full=True)
if len(sys.argv) > 3:
    xref = imgs[int(sys.argv[3])][0]
else:
    xref = max(imgs, key=lambda im: im[2] * im[3])[0]
img = Image.open(io.BytesIO(doc.extract_image(xref)["image"])).convert("RGB")

a = np.asarray(img).astype(int)
nonwhite = a.min(axis=2) < 235
active = nonwhite.mean(axis=0) > 0.5
spans, start = [], None
for x, v in enumerate(active):
    if v and start is None:
        start = x
    if not v and start is not None:
        spans.append((start, x))
        start = None
if start is not None:
    spans.append((start, len(active)))
spans = [s for s in spans if s[1] - s[0] > 200][:2]
if len(spans) < 2:
    sys.exit(f"没切出两张图（找到 {len(spans)} 段），请手动裁剪")

for (x0, x1), name in zip(spans, ["pair_A", "pair_B"]):
    ys = np.where(nonwhite[:, x0 + 20:x1 - 20].mean(axis=1) > 0.9)[0]
    crop = img.crop((x0 + 2, ys.min() + 2, x1 - 2, ys.max() - 1))
    crop.resize((crop.width * 2, crop.height * 2), Image.LANCZOS).save(name + ".png")
    print(name, crop.size)
